# Rule reference

| Rule                                                              | What it checks                                                           |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------ |
| [`expression-complexity`](rules/expression-complexity.md)         | Limits the number of logical operators in one expression.                |
| [`named-conditions`](rules/named-conditions.md)                   | Keeps inline `&&` and `\|\|` out of branch and loop conditions.          |
| [`no-duplicate-strings`](rules/no-duplicate-strings.md)           | Flags string values repeated within a file.                              |
| [`no-magic-strings`](rules/no-magic-strings.md)                   | Requires names for string literals used in comparisons and switches.     |
| [`no-shallow-type-predicate`](rules/no-shallow-type-predicate.md) | Flags type predicates whose container check does not establish the type. |
| [`uppercase-primitive-const`](rules/uppercase-primitive-const.md) | Requires UPPER_CASE names for top-level primitive constants.             |
